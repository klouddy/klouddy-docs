# Intake Types

Use this section when the quick reference helps you narrow the field, but you still need a better starting point for design choices.

Still deciding? Start with the [Intake Quick Reference](../intake-quick-reference.md).

## Choose a direction first

Use `passive intake or claw` when:

- the gamepiece is awkward, large, fragile, or easier to grab directly
- your robot only needs careful one-piece control
- your team needs the simplest mechanism it can finish and trust early

Use `active intake` when:

- the game rewards repeated floor pickup and faster cycles
- driver alignment needs to be more forgiving
- your robot can support a clean intake and transfer path

## How to use these pages

- Use the quick reference first to compare overall intake families.
- Use the passive page when you are deciding whether direct grabbing is good enough for the full game cycle.
- Use the active pages to compare which powered intake style best fits the gamepiece and robot layout.
- Treat the transfer path as part of the intake system, not an afterthought.
- Prefer the intake your team can finish early, test often, and maintain between matches.
