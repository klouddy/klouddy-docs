# Electrical and Wiring Best Practices

Keep the electrical system clean, easy to inspect, and easy to troubleshoot.

## Best practices

- Route wires deliberately
  Avoid loose wiring that can snag, bend sharply, or rub on moving parts.
  Learn more: [GM0 Wiring Guide](https://gm0.org/en/latest/docs/power-and-electronics/wiring.html)

- Add strain relief
  Connectors fail less often when wires are supported and not pulling on ports.
  Learn more: [GM0 Connectors and Wires](https://gm0.org/en/latest/docs/power-and-electronics/connectors-and-wires.html)

- Label ports and devices clearly
  Clear names make configuration, repairs, and inspections much easier.
  Learn more: [FTC Docs Configuring Your Hardware](https://ftc-docs.firstinspires.org/en/latest/hardware_and_software_configuration/configuring/index.html)

- Keep hub connections neat and correct
  Motors, servos, sensors, and power leads should be connected carefully and checked often.
  Learn more: [FTC Docs Connecting Devices to a Hub](https://ftc-docs.firstinspires.org/en/latest/hardware_and_software_configuration/connecting_devices/index.html)

- Treat batteries as part of robot reliability
  Charge, label, rotate, and inspect batteries consistently.
  Learn more: [GM0 Control Systems](https://gm0.org/en/latest/docs/power-and-electronics/control-system.html)

- Make troubleshooting fast
  A clean layout helps students quickly answer: what is connected, where, and why?
  Learn more: [GM0 Electronics Tips and Tricks](https://gm0.org/en/latest/docs/power-and-electronics/tips-and-tricks.html)
