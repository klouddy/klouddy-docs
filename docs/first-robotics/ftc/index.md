# FTC Overview

FIRST Tech Challenge (FTC) is a robotics program for students in grades 7-12. Teams design, build, program, and test robots for a new game challenge released each season.

FTC is more than robot building. Students also learn how to work as a team, communicate design choices, document progress, and improve through iteration.

## What students usually do in FTC

- Learn the game and scoring rules
- Brainstorm strategy before building
- Prototype and test mechanisms
- Build and wire the robot
- Program teleop and autonomous behavior
- Practice driving and teamwork
- Record design changes and lessons learned

## Suggested approach for new students

1. Read the season rules and scoring summary.
2. Learn the main team roles.
3. Start with simple, reliable designs.
4. Build, test, and improve in small steps.
5. Keep notes on what worked and what did not.
